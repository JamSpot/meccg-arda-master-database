# MECCG Arda Master Database

A research-first master database and website for Hero Arda in the Middle-earth Collectible Card Game (MECCG).

## Project principles
- Canonical Gandalf Gene Arda is the primary reference point.
- Other Arda lists and rulesets are clearly labelled comparisons or variants.
- No proxies: acquisition work is for genuine physical MECCG cards.
- Source discrepancies are recorded rather than silently corrected.
- Minion Arda is outside scope unless explicitly requested.

## Current research focus
The central forensic task is reconciling the original Gandalf Gene Arda spreadsheet with the published summary of 377 distinct cards / 695 physical cards.

The spreadsheet currently parses to a different working checksum: 374 distinct named cards / 699 physical copies among rows with numeric quantities. That discrepancy is deliberately preserved for investigation.
