# Sources & Downloads

## Primary and high-value sources

### Council of Elrond — Gandalf Gene
https://councilofelrond.org/forum/viewtopic.php?f=37&hilit=gandalf+gene&p=23844&t=2870

Original 2016 post and GandalfGeneArda.xls attachment. This remains the primary quantity source for the canonical deck.

### Council of Elrond — Arda Ten Years Later
https://www.councilofelrond.org/forum/viewtopic.php?t=3944

Historical context and later variants.

### CardGameGeek — Gandalf Gene transcription
https://cardgamegeek.com/database/decks/27774d75-5a7d-4509-ba89-8cb556f3bfc5

Independent transcription. It reports 178 entries and notes two missing hazards, so it is a checksum/comparison source rather than a complete authority.


### BoardGameGeek — My Solo Arda Build with Session Report
https://boardgamegeek.com/thread/1058232/my-solo-arda-build-with-session-report

Published 22 October 2013, with later turns added on 14 November 2013. Describes a personal solo-Arda adaptation using separate MP, Ring, Resource, Minor Item, two Character, Hazard and Site decks. The author generally uses one of each owned card and selected multiples of common resources/hazards, and excludes The Lidless Eye, The White Hand and The Balrog. The tested scenario targets 25 Marshaling Points in eight turns and draws hazards at four times the site's printed number when travelling, twice when staying. The author describes the rules as experimental and makes some ad hoc solo rulings. No exact quantity spreadsheet or deck file was verified. This is a solo-method comparison, not a canonical card-quantity source.

### Independent printed-card catalogue — Elven Forest
https://elvenforest.narod.ru/meccg/cards/meccg_list.html

An independent set-coded catalogue used for a targeted expansion cross-check. It lists Army of the Dead and The White Tree under The Wizards (TW), Peril Returned under The Dragons (TD), and Uruk-lieutenant and Wild Trolls under The Lidless Eye (LE). This is a metadata cross-check only, not an Arda quantity authority; validate remaining fields against the Council of Elrond database.

### Council of Elrond card database
https://github.com/council-of-elrond-meccg/meccg-cards-database

Useful for card identity, corrected text, errata and current database information. Repository last updated 19 September 2026. The current tree includes [cards.json](https://github.com/council-of-elrond-meccg/meccg-cards-database/blob/master/cards.json) ([raw download](https://raw.githubusercontent.com/council-of-elrond-meccg/meccg-cards-database/master/cards.json), 4,163,611 bytes) and [changes-guide.xlsx](https://github.com/council-of-elrond-meccg/meccg-cards-database/blob/master/changes-guide.xlsx) ([raw download](https://raw.githubusercontent.com/council-of-elrond-meccg/meccg-cards-database/master/changes-guide.xlsx), 22,147 bytes). These are metadata/text verification resources, not Arda quantity sources. The project asks third-party community projects using its database to acknowledge it and notify the Council of Elrond.

### BoardGameGeek MECCG files
https://boardgamegeek.com/boardgame/1915/middle-earth/files

Important archive for downloadable MECCG files. The current archive lists MECCG Card List v1.13 as an XLS (card information, rarity and distribution; dated 6 March 2010), Starter Set Decks Lists as an XLS, and an Arda deck example as a PDF. Confirm the specific file format on each attachment page before describing it as a spreadsheet.

### MeCCG.com lists and downloads
https://meccg.com/cards/lists-and-downloads/

Useful card-finder, card lists, fixed lists and Challenge Deck resources. Direct files now documented for cross-checking:
- [MeCCG List of Cards — XLS](https://meccg.es/meta/cards/list/MeCCG%20List%20of%20Cards.xls) — version/date not shown on the landing page; parse before relying on its coverage.
- [Full Spoiler List — PDF](https://meccg.es/meta/cards/MeCCG%20Full%20Spoiler%20List.pdf) — expansion-organized card reference; its front matter says updated February 2007.
- [Fixed Sets — PDF](https://meccg.es/meta/cards/list/Fixed%20Sets.pdf) — product reference, not an Arda quantity source.

### Archived MECCG_Card_List.xlsx — coverage limitation

A locally available copy was compared with the working inventory. It has 144 catalogue rows, 45 normalized name overlaps with the 374 numeric-quantity inventory, and no populated rarity values. Some matching names are labelled with a different set, so this copy may reflect specific printings rather than the exact source printing in the Arda workbook. Treat it as a partial metadata cross-check only; do not use it to overwrite expansion assignments or quantity counts.

### MeCCG.com published deck database
https://meccg.com/decks/

Published constructed-deck examples and strategy context. These decks are not automatically Arda lists and should not be merged into the canonical pool.

## Card-reference and deck-tool cross-checks

### Collected Rulings File 22
https://meccg.com/rules/collected-rulings-and-errata/crf-22/

Published 21 January 2026. Use this to verify current rulings and clarifications, not Arda quantities.

### Samwise — MECCG Card Gallery & Deckbuilder
https://github.com/SylvanSign/samwise

Offline card gallery and deckbuilder for standard MECCG cards, with filters, local save/load, human-readable deck files and Cardnum-format import/export. Its README says the card metadata comes from Cardnum and that Dream Cards are not currently included. This is a tool/format cross-check, not an authoritative Arda card pool.

### MECCG Online
https://github.com/Heinrich-Barth/meccg-online

Supports Arda-format play, card browsing, deckbuilding and importing. Its README warns that included generic sample data is not suitable for full deckbuilding, so do not use that sample data as an authority for card counts.

### Additional Arda variant: The Houses of the North

[ARDA with Dream cards — The Houses of the North](https://councilofelrond.org/forum/viewtopic.php?t=4531) is an itemized, 888-card Dwarf-themed Arda list. The post was first published in November 2021 and last edited in July 2025. It groups cards by pile and records quantities/set codes, but includes Dream Cards, optional UEPs and some unreleased-set experiments. Keep it as a separate variant; it is not a standard Hero Arda quantity authority and is not a downloadable spreadsheet.


### Published Arda Rules 4.0 PDF

https://lureofmiddleearth.com/wp-content/uploads/2016/03/arda_4.0_en.pdf

A 25-page published Arda rules reference credited to Joe Bisz (concept) and Joe Bisz / Eric Dané (design). The Basic Arda Game is shared-deck multiplayer (2–7 players) and recommends a 250+ Play Deck with equal resources and hazards, about 15 MP cards per player (often around 100), a Roving Character Deck of about 70 for larger games, and a 30–35 card Minor Item Offering Deck. These are general sizing guidelines, not exact card quantities. The 1:1 Play Deck recommendation differs from the current Gandalf Gene transcription (171 resources and 252 creatures/hazards); preserve that difference rather than silently changing source counts.

Targeted checks of the [Council of Elrond cards.json](https://raw.githubusercontent.com/council-of-elrond-meccg/meccg-cards-database/master/cards.json) confirm these IDs/set codes: Army of the Dead TW-193 (TW), The White Tree TW-348 (TW), Peril Returned TD-54 (TD), Uruk-lieutenant LE-96 (LE), and Wild Trolls LE-100 (LE). This verifies card metadata but provides no Arda copy quantities. The full JSON remains too large for one-shot parsing through the current GitHub connector; complete automated matching is still outstanding.

## Source hierarchy

For reconstructing the canonical Gene deck:
1. Original Gandalf Gene deck/spreadsheet
2. Original Council post description
3. Independent transcription/checksums
4. Historical discussions and separately labelled Arda variants
5. Current card databases for identity, expansion, rarity and errata verification
6. Deckbuilding software as a technical cross-check only
