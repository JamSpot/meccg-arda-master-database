# Rules & Variants

## Start with the Arda Basic Game

The main Arda format is a shared-deck multiplayer game for 2–7 players. All players draw from common Play, Marshalling Points, Roving Character and Minor Item Offering piles. Use the [Arda Multiplayer Guide](arda-multiplayer-play.html) for setup and the complete Basic Game turn flow, based on the published Arda Rules 4.0.

## Published Arda Rules 4.0

The 2016 Rules 4.0 document describes the Basic Game, recommended pile sizes, multiplayer setup, player turns, trading, calling the Council and simultaneous active turns for 5–7 players. It also includes optional Expanded World and scenario material. Optional material should be agreed before play; do not silently mix it into the Basic Game.

[Read Arda Rules 4.0 (PDF)](https://lureofmiddleearth.com/wp-content/uploads/2016/03/arda_4.0_en.pdf)

## Compiled Arda Ruleset — Hero

The March 2024 Compiled Arda Ruleset – Hero is a rules reference based partly on the Middle-earth Arda Game, Arda Revised and Gandalf Gene's Arda Deck.

It is not treated as a replacement cardlist for the 2016 Gandalf Gene deck. It includes additional clarifications and optional variants.

[Find the compiled ruleset on BoardGameGeek](https://boardgamegeek.com/boardgame/1915/middle-earth/files)

## Arda Revised

Arda Revised is a rules/deck-construction variant rather than a fixed Gandalf Gene cardlist. It uses a communal Play Deck and separately constructed character, MP, Ring and Minor Item decks.

[Find Arda Revised on BoardGameGeek](https://boardgamegeek.com/filepage/98645/arda-revised)

## Arda-specific solitaire variants

Several solo adaptations have been identified. They are separate methods, not one combined ruleset:

- **2013 BGG solo build:** experimental personal variant with MP, Ring, Resource, Minor Item, two Character, Hazard and Site decks; the session report describes a 25 MP / eight-turn goal and hazard counts scaled differently for travelling and staying.
- **Kober Arda Solitaire v0.2 (2015):** separate solo rules PDF; the available comparison notes that it retains travel to appropriate sites for Greater/Major Items, Information and Gold Rings.
- **Callasmar solo-Arda variant:** described as pairing a site with a playable card, a different approach to site access.
- **Spanish simplified Arda (2022):** a separate Arda summary with a solitaire mode added; full procedure still requires extraction.

See the [Arda-specific Solo Play guide](arda-solo-play.html) for the source-by-source comparison and the limits of what has been verified. Do not import the conventional Hero Solo Academy's Hero/Hazard decks or expedition sequence into Arda.

## Arda Intro Game — multiplayer teaching variant

[Download the 2024 Arda Intro Game PDF (127.6 KiB)](https://www.councilofelrond.org/forum/download/file.php?id=4315). This is a separate 2–5 player introductory multiplayer variant adapted from several Arda sources, including the Compiled Arda Ruleset — Hero, Arda Revised and Gandalf Gene. It uses paired MP-resource/site cards and separate Character, Minor Item, Ring, Haven and Avatar piles. Its 505-card METW/METD no-rares pool and 606-card all-rarities pool are alternative teaching lists, not the canonical Gene pool. **It is not a solo rules source**; use the Arda-specific solo guide and the separately documented solo variants for solo play. The all-rarities list includes official promotional printings, which must be kept outside base expansion totals. See the [3 November research watch](research-watch-2026-11-03.html).

## Principle

Rules variants can explain how a card is used, but should not silently alter the historical card inventory. Keep multiplayer rules, solo adaptations, card pools and each optional rules version tied to their own source.
