# Research watch — 9 November 2026

## Summary

This pass identified two fresh BoardGameGeek discussion leads directly about building Arda card pools and modular solo play, plus a 2026 Gen Con Hero Arda event listing. These confirm current community interest and physical-card play, but **none supplies a new verified card list or downloadable pool**. The existing card-quantity baseline is unchanged.

## 1. New BoardGameGeek discussion leads

The current [BoardGameGeek Middle-earth game page](https://boardgamegeek.com/boardgame/1915/middle-earth) surfaced two recent hot threads:

- **“Turning MECCG into a Modular Solo Board Game – ARDA, Variants & Card Lists. Is it possible?”** by proxegentyc, listed as approximately 23 days old at the time of this check.
- **“Looking for card lists to build ARDA decks”** by proxegentyc, listed as approximately 21 days old.

These titles are highly relevant leads because they may attract new Arda pool references or links. However, BoardGameGeek blocked direct thread retrieval in this pass (HTTP 403), and the indexed game-page view does not expose the thread IDs, full posts, replies or attachments. I therefore cannot verify whether either discussion contains an actual decklist, spreadsheet, card file or only a request for help.

**Status:** watchlist leads only. Do not treat them as published decklists and do not import any quantities from them until the thread contents and any attachments can be inspected.

## 2. Gen Con 2026 — current physical Hero Arda event

The [official Gen Con event listing](https://www.gencon.com/events/303679) records **“Middle-Earth CCG: ‘Arda’ Format”**, run by Prof Joe Games during Gen Con Indy, 30 July–2 August 2026.

The listing describes a casual shared-deck game for 4–18 players and says that, for 2026, almost all cards would be official versions rather than Virtuals. It is useful evidence that large-group Hero Arda play remains active and that an event organizer was deliberately prioritizing official physical card versions.

The listing does **not** publish the card pool, expansion quantities, pile counts or deck file. It is community/event evidence, not a quantity source.

## 3. Rules reference checked — not a new pool

The [Arda Rules 4.0 PDF](https://lureofmiddleearth.com/wp-content/uploads/2016/03/arda_4.0_en.pdf) remains the general published Basic Game reference: 2–7 players, a shared Play Deck of 250+ cards with equal resources and hazards recommended, an MP Deck usually around 100 cards, a Roving Character Deck using most available characters, and a Minor Item Offering Deck around 30–35 cards.

These are sizing guidelines, not a fixed published card list. They must not be substituted for the specifically curated Gandalf Gene build or for solo variants.

## 4. Downloadable files and decklists

No new downloadable Arda XLS/XLSX, .dek, .deck, PDF card pool or other complete Arda inventory was verified in this pass.

The existing source register remains the best available set of distinct comparison assets:

- Gandalf Gene's original Hero Arda XLS — primary canonical quantity source; binary hash comparison still outstanding.
- Thorondor's 2015 no-rares Arda XLS — independent low-rarity comparison pool; attachment identified but not extracted.
- Jose-san's BGG Arda example XLS — parsed locally as 370 named cards / 691 copies across alignments; its Hero/Neutral/Avatar subset is 322 rows / 623 copies. Keep separate from Gandalf Gene.
- Jared Brayshaw's 2024 Arda Intro Game PDF — two sample pools, normalized separately; not merged into the canonical pool.
- Kober's 2015 Arda Solitaire v0.2 PDF — solo rules, not a quantity list; binary extraction still outstanding.
- Arda Revised and the compiled Hero ruleset — rules references, not card-pool inventories.

The ten official Challenge Deck files and MeCCG catalogue workbook remain card/deck reference assets only, not Arda pools.

## 5. Quantity baseline — unchanged

The Gandalf Gene source remains at **699 explicit copies**:

| Expansion | Explicit copies |

| The Wizards (METW) | 552 |
| The Dragons (METD) | 108 |
| Dark Minions (MEDM) | 32 |

The independent CCG Collector report remains **695 copies**, leaving a four-copy discrepancy. *Army of the Dead* and *The White Tree* remain named source rows with blank quantities. No new evidence resolves either issue.

The separate CCG Collector distinct-card breakdown is a count of card identities by expansion, not copies: 300 METW, 59 METD, 14 MEDM, 2 MELE and 1 MEBA. Those figures sum to 376, while the post says 377 distinct cards; this counting-convention difference remains recorded separately from the physical-copy discrepancy.

No quantities have been added, removed, or reallocated by expansion.
