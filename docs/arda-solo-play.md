# Arda-Specific Solo Play

> **Scope:** This page covers solo adaptations of the Arda format only. It is not the conventional MECCG Hero Solo Academy and does not use that Academy's fixed Hero Resource deck, separate complementary Hazard deck, or Rivendell-to-Moria teaching expedition.

## Start here: choose one Arda solitaire method

Arda is normally described through a format with specialised card piles. Solo adaptations change how those piles, site travel, opposing hazards and scoring are handled. The sources collected for this project describe several different approaches. They are not interchangeable, and there is no single universal solo-Arda ruleset established by the sources reviewed so far.

### 1. BoardGameGeek — My Solo Arda Build with Session Report (2013)

[Read the original session report](https://boardgamegeek.com/thread/1058232/my-solo-arda-build-with-session-report)

This is a personal, experimental solo adaptation. The report describes separate:

- MP deck
- Ring deck
- Resource deck
- Minor Item deck
- two Character decks
- Hazard deck
- Site deck

The author generally used one copy of each owned card, with selected multiples of common resources and hazards, and excluded The Lidless Eye, The White Hand and The Balrog. The stated challenge was to reach **25 Marshaling Points in eight turns**. The report describes drawing hazards at four times the site's printed number when travelling and twice that number when staying.

**How to use this source:** treat it as one complete homebrew design to study, not as official Arda rules or the canonical Gandalf Gene pool. The report includes experimental and ad hoc rulings. The precise card-by-card deck composition was not supplied as a verified downloadable list in the research pass.

### 2. Kober — Arda Solitaire v0.2 (2015)

[Find the Arda Solitaire v0.2 source on Council of Elrond](https://councilofelrond.org/forum/viewtopic.php?t=2578)

This is a separate Arda-specific solitaire rules document. A 2016 discussion compares it with Callasmar's approach: Kober's method preserves travel to the appropriate sites for Greater/Major Items, Information and Gold Rings rather than simply pairing a site with a playable card.

**How to use this source:** keep Kober's site/travel logic intact if choosing this method. Do not import Callasmar's site/card pairing or the 2013 BGG hazard-draw multipliers unless the original Kober document says to. The PDF binary was listed on the forum but was not retrievable for full rule-by-rule extraction during this update.

### 3. Callasmar — solo Arda variant

[Find the Callasmar variant on BoardGameGeek](https://boardgamegeek.com/filepage/87333/variante-a-las-reglas-arda-para-jugar-en-solitario)

The available comparison describes Callasmar's approach as pairing a site with a playable card. This changes the way site access and card play are linked.

**How to use this source:** regard it as a separate variant from Kober. Do not combine its site/card pairing with Kober's site-travel restrictions or the BGG 2013 session report's hazard multipliers without checking the original rules.

### 4. Spanish simplified Arda with solitaire mode (2022)

The source register identifies [TierraMediaF2.pdf](https://boardgamegeek.com/boardgame/1915/middle-earth/files) as a Spanish Arda summary with a solitaire version added. It is another distinct rules presentation. Its full solo procedure has not yet been extracted and translated, so this page does not invent its setup or turn sequence.

## Do not mix the variants

| Rule element | 2013 BGG solo build | Kober v0.2 | Callasmar | Spanish summary |
|---|---|---|---|---|
| Distinct solo source | Yes | Yes | Yes | Yes |
| Separate Arda piles described | Yes | Requires original PDF | Site/card pairing noted | Requires source extraction |
| Special site/travel handling | Hazard count scales with travel/staying | Retains travel to appropriate sites | Site paired with playable card | Not yet extracted |
| Published target / end condition recorded here | 25 MP in 8 turns | Not verified | Not verified | Not verified |
| Complete procedure verified in this project | Partial session-report detail | No | No | No |

The table records only details supported by the source notes. “Not verified” means the original rule document still needs to be obtained and checked; it does not mean the variant has no such rule.

## Arda solo setup: what you must decide before laying out cards

1. **Choose the variant first.** Write down the source and version you intend to follow.
2. **Choose a compatible Arda card pool.** The [Gandalf Gene list](gandalf-gene.html) is the project's canonical comparison point, but the 2013 BGG solo build describes its own collection-based exclusions and multiples. Do not assume those pools are identical.
3. **Use only the piles required by that variant.** The 2013 BGG report lists MP, Ring, Resource, Minor Item, two Character, Hazard and Site decks. Other methods may organise these differently.
4. **Keep all piles and discards separate as the selected source specifies.** Do not substitute the conventional Solo Academy's 38-card Hero play deck and 30-card Hazard deck.
5. **Record the variant's hazard procedure before the first turn.** In particular, do not treat the 2013 report's four-times/travelling and two-times/staying hazard counts as a general Arda rule.
6. **Record the target and turn limit.** The 25 MP / eight-turn goal belongs to the 2013 BGG build as described in that report; do not apply it to Kober, Callasmar or the Spanish variant without source support.
