# Arda Overview

## What Arda is

Arda is a shared-deck MECCG format. In the Arda Basic Game, all players draw from common piles rather than bringing their own separately constructed resource and hazard decks. The published Arda Rules 4.0 describes a game for **2–7 players**, built around improvisation, shared card access and trading between players.

Arda is not simply conventional two-player MECCG with a larger card pool. It has its own shared pile structure, setup, drafting, resource/hazard turn roles and multiplayer interaction.

## Choose how you want to play

- **Multiplayer Arda (the main format):** use the [step-by-step Arda Basic Game guide](arda-multiplayer-play.html). It covers shared piles, setup, wizard and character drafting, turns, hazard passing, trading, simultaneous turns for larger groups and the Council.
- **Solo Arda:** use the [Arda-specific solo guide](arda-solo-play.html). It compares published solo adaptations and keeps their procedures separate.

The solo guide is not a substitute for the multiplayer rules. Likewise, the multiplayer guide does not assume a solo opponent or use the conventional Hero Solo Academy's fixed Hero and Hazard decks.

## Canonical card-pool reference

The principal fixed decklist in this project is Gandalf Gene's Arda Deck, published on the Council of Elrond forum in December 2016.

The original post describes:
- 171 resource cards
- 252 creature/hazard cards
- a 423-card Play Deck
- a One Ring strategy in which only Gollum + Gollum's Fate can win with the One Ring
- a hazard package heavily based on METW Orcs, Trolls and Nazgûl
- all Dragons and Dragons At Home, but no Dragons Ahunt
- an MP deck mainly based on METW, with Dragons hoard items and a small number of Dark Minions cards
- a Roving Character Deck containing all characters, promotions and Strider from The Balrog
- no Under-deeps sites
- no optional rules or Arda errata in the original version

The general Arda Rules 4.0 deck-building recommendations are not identical to Gandalf Gene's particular card counts. The database preserves those differences rather than changing one source to fit another.

## Separation

The database distinguishes:
1. The Arda Basic Game multiplayer rules.
2. Arda-specific solo adaptations.
3. Canonical Gandalf Gene card pool.
4. Historical or alternative Hero Arda lists.
5. Revised and expanded rules variants.
6. Unresolved or disputed data.

A later Arda card or variant does not automatically belong in the canonical Gene collection.

## Research rule

When sources disagree, the disagreement is retained and documented until card-level reconciliation establishes why the numbers differ.
