# Arda research watch — 17 November 2026

## Result

No new downloadable **ICE-only Hero Arda card-pool spreadsheet or complete deck file** was verified in this pass. The canonical card quantities are unchanged. The useful new discovery is a set of printable Arda table aids from the Council of Elrond archive; these help organise play but do not contain a card inventory.

## New practical downloads: Arda placemats

The Council of Elrond's [Arda Goodies thread](https://www.councilofelrond.org/forum/viewtopic.php?f=37&t=1702), opened by Thorsten the Traveller on 23 March 2011, lists two downloadable PDFs made by Joe:

- [Roving Character-Placemat1.pdf — 451.92 KiB](https://www.councilofelrond.org/forum/download/file.php?id=389) — a dedicated layout aid for the face-up Roving Character area.
- [Placemat for All Piles ARDA.pdf — 3.11 MiB](https://www.councilofelrond.org/forum/download/file.php?id=388) — a table layout aid for the shared Arda piles.

An earlier 30 July 2009 [Components and Game Aids for ARDA thread](https://www.councilofelrond.org/forum/viewtopic.php?f=37&t=1218) also offers [Roving_Character_Deck-Placemat.pdf — 451.92 KiB](https://www.councilofelrond.org/forum/download/file.php?id=240). It has the same listed file size as the 2011 roving-character placemat, but the two attachment binaries have not been hash-compared, so they are recorded separately.

These are **printable playing aids, not card lists**. The forum describes the roving-character aid as part of a larger 17 × 23 inch (432 × 590 mm) map-and-token approach for group games. Direct browser retrieval of the PDF attachments returned an unsupported binary response in this research environment; the forum's attachment links remain available for manual download.

## Additional rules-only lead

The 2010 [Arda Game Variant: The Mission Cards](https://www.councilofelrond.org/forum/viewtopic.php?f=37&t=1478) proposes optional region-card objectives that award Region Points for playing MP-bearing resources in selected regions. It explicitly keeps those Region Points separate from Marshaling Points and the 20-MP Council threshold. This is a play variant only: no new card pool, decklist or quantity data is supplied. It should not be silently added to Basic Arda.

## Rechecked repositories and archives

- The [Council of Elrond card database repository](https://github.com/council-of-elrond-meccg/meccg-cards-database) still provides its 3.97 MB `cards.json` and 22,147-byte `changes-guide.xlsx`. It is a current card identity/text/errata reference, not an Arda pool. Its README requires third-party projects using the data to acknowledge the source and notify the Council of Elrond. The full JSON was too large for one-shot retrieval through the connected GitHub file reader in this pass; no new automated inventory comparison is claimed.
- [MeCCG.com Lists and Downloads](https://meccg.com/cards/lists-and-downloads/) continues to expose the existing card-list XLS, character XLSX, Challenge Deck ZIP and PDF references. The XLS and ZIP endpoints returned binary-format responses that this browser reader cannot parse; none is an Arda deck.
- [MeCCG.com Decks](https://meccg.com/decks/) is a published constructed-deck archive. Its current landing page does not expose a verifiable Arda-specific card-pool file.
- The [BoardGameGeek MECCG files archive](https://boardgamegeek.com/boardgame/1915/middle-earth/files) still identifies Jose-san's Arda deck example as an XLS, alongside rules and playing aids. No new Arda spreadsheet was listed in the current archive review.

## Card-pool decision

No new eligible card quantities were imported. Keep the existing sources separate:

- Gandalf Gene's 2016 Hero Arda workbook remains the primary fixed-pool reference.
- Jose-san's 2022? / BGG Arda example remains a separate Hero/Neutral/Avatar comparison pool; do not merge it.
- Thorondor's 2015 no-rares XLS remains an identified but unparsed comparison list.
- Dream Card, custom, virtual and Minion Arda material remains outside the user's ICE-only Hero scope.
